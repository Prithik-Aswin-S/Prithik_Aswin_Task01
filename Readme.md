# Online Examination Applications
## Description
The Online Examination Application is a web-based platform developed to conduct online tests efficiently and securely. The system provides a seamless examination experience for users by allowing them to log in, attempt multiple-choice questions, manage their profiles, and submit exams automatically when the timer expires.
## Features
- User Authentication (Login System)
- Update Profile Information
- Change Password Functionality
- Multiple Choice Question (MCQ) Examination Interface
- Real-Time Examination Timer
- Automatic Submission on Time Expiry
- Secure Session Management
- Logout Functionality
- Responsive User Interface
## Tech Stack
- React.js
- TypeScript
- Tailwind CSS
- Supabase (if used)
- HTML5
- CSS3
- JavaScript
